# 0.4.0：中文标签、双 RJ 与重试行为

本文记录 0.4.0。0.4.1 已增加失败跳过、翻译版关联跳转和地区限制提示，见 [0.4.1 升级说明](0.4.1升级说明.md)。

安装 `artifacts/ysplayer-0.4.0-preview.apk` 可覆盖旧预览版。应用版本号为 4，数据库自动从 1 / 2 升级到 3。保留作品封面、手填署名、收藏、目录索引、列表、进度和已有官方缓存。

## 取消失败硬冷却

移除客户端 `blockedUntil` 和补全队列的失败冷却检查。网络超时、DNS、TLS、HTTP 403、解析失败等不会再让 APK 锁定一小时或一天。升级后不需要清除应用数据，旧冷却值会忽略并清理。

每次实际请求起始仍至少间隔 10 秒，包括 robots.txt、产品页、分区回退及允许的重定向。全应用串行，上次请求时间跨进程保存；若站点机器人规则声明更长的抓取间隔则遵循该规则。机器人规则的 24 小时缓存不是失败冷却。

失败记录保留具体异常类型、HTTP 状态和服务器给出的 `Retry-After`，不再统一显示成“DLsite 暂停访问”。访问受限或网络错误会结束当轮，可手动重新补全；服务器等待时间仅作为提示，不转换为 APK 的本地阻拦。不会在失败后自动无限重试，成功数据继续缓存。

## 双 RJ 目录

同一作品文件夹包含两个 RJ，按出现顺序选择第一个作为主编号，包括以下写法：

```text
RJ123456RJ876543 作品名/MP3/01.mp3
RJ123456 RJ876543 作品名/WAV/01.wav
[RJ123456][RJ876543] 作品名/中文字幕/01.srt
```

它们都以 `RJ123456` 关联作品和 DLsite 信息，不再根据第二个翻译版编号另选远程作品。首个带编号父目录为双 RJ 时，其下的语言子目录也沿用该主编号。完全不同的单 RJ 父子目录冲突仍保留待确认提示。

升级时根据已有轨道路径修正旧版无法确定的双 RJ 作品，保留原作品 ID，避免原有封面、列表和进度失联；重新扫描也复用已修正的记录。

## 官方中文标签

产品页明确请求 `?locale=zh_CN`，并设置简体中文优先的语言头。只从官方简体中文页面的“分类”栏提取标签编号和显示名，社团 / 声优栏同时支持中文标题。原始声优署名保持官方名称，不翻译姓名。

新增 `credit_tags` 存储 RJ、官方标签编号、中文名称及顺序。作品记录保存显示标签和“标签已查询”标志，成功查过但没有标签的页面同样可以缓存，避免反复请求。若未取得中文分类栏，不把日文标签写作中文，也不覆盖原有署名缓存。

旧版仅有社团 / 声优的缓存标记为尚未获取中文标签，因此会补查一次；之后新导入的相同 RJ 可直接离线复用。中文标签在双列卡片、原列表和作品详情展示，作品库搜索与筛选也包含标签。

## 验证

2026-10-23 的虚构的中日文署名 / 分类栏作为解析回归样本。70 项自动测试通过，0 失败 / 跳过；测试包括 API 29 / 35 的数据库升级、旧署名缓存补标签、中文标签 ID 和语言验证、缓存离线复用、DNS / 429 后不受长冷却阻拦、10 秒串行限速、双 RJ 旧索引修正、标签界面搜索筛选，以及原有播放 / 字幕 / 封面测试。

开发机未连接手机，仍需设备验证手机网络的 DLsite 可达性。若再次失败，界面现在会显示具体网络异常或 HTTP 状态，便于定位；本次不加入账号 Cookie 导入。

调试和精简预览构建成功；Lint 为 0 错误、22 条建议警告。已核对最低 API 29、版本号 4，以及与 0.3.0 一致的 APK 签名。
