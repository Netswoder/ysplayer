## 在Android 手机 上首次试用

安装 `artifacts/ysplayer-0.1.0-preview.apk`。将少量代表性作品和已有字幕复制到手机可访问的子目录，例如 `Download/DLsite`，通过应用添加该目录。电脑目录不会自动变成手机数据来源。

若使用 USB 调试，可连接并在手机上确认电脑授权后执行：

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r artifacts/ysplayer-0.1.0-preview.apk
```

首次安装前记录手机实际 Android / 厂商系统 版本。以下项目本次尚未完成设备验证：

- [ ] 编辑声优 / 社团后筛选正确；多声优作品可按任一声优找到。
- [ ] 自定义列表添加整部作品或单轨，排序、移除和连续播放正常。
- [ ] MP3、WAV 等实际音频正常播放、拖动、切轨和变速。
