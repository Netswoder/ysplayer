# 0.4.1：失败跳过与翻译版关联跳转

应用版本号 5 / 0.4.1-preview，数据库仍为版本 3。可覆盖旧版，保留缓存、目录授权和播放数据。

## 单个失败不终止整轮

补全时 HTTP 错误、网络异常、地区限制或页面解析失败都只记为该作品失败，继续下一个未补全作品。成功结果照常保存；下次补全只查询仍缺失的信息，失败记录不设置本地长冷却。取消任务仍中断后续排队，不在失败后无限重试当前作品。

所有实际请求仍共用串行客户端，至少间隔 10 秒，包括机器人规则、页面跳转和分区回退；服务器的 Retry-After 保留为提示。

## 翻译版跳转结构示例

以下为使用虚构编号说明的翻译版跳转结构：

```text
RJ99000002.html?locale=zh_CN
  HTTP 302
RJ99000003.html/?translation=RJ99000002
```

这是 DLsite 返回的翻译版关联。0.4.0 仅允许同 RJ 的公开作品跳转，因编号变化及路径末尾斜杠而拒绝，因此报告 HTTP 302。

0.4.1 允许同官方 HTTPS 站点中明确携带 `translation=请求的RJ` 的作品页跳转，兼容末尾斜杠、保留翻译关联并补上中文参数；本地缓存键仍为原请求 RJ。未关联的其他作品、站外、登录或验证跳转继续拒绝。

继续访问落地页时，服务可能返回 HTTP 200，但页面正文明确提示“您所在的国家・区域无法购买此作品”。这类响应不包含署名和分类栏，不能记作成功缓存，也不能用页面面包屑中的翻译社团推断原社团。新版本明确显示地区限制原因并跳到下一作品。修正跳转不保证受限制作品立即能补全。

## 手机 Clash 与默认网络

播放器使用普通 `HttpURLConnection` 和系统默认网络，没有绑定其他网络或强制 `NO_PROXY`。Clash 使用 Android VPN/TUN，且音声书架未被排除时，流量可以由它接管；是否最终代理出站取决于分流规则。可在 Clash 的连接记录中检查应用 `com.ysplayer` 到 `www.dlsite.com` 的请求、命中规则，以及 DIRECT 或具体代理链。

只开启一个本地 HTTP/SOCKS 监听端口并不等于所有应用自动使用该端口。播放器不额外硬编码本地代理地址。

## 验证

76 项自动测试通过，0 失败 / 跳过，包含 API 29 / 35 的 403 后继续处理并成功缓存下一作品、下轮只重试失败项，以及每次跳转仍限速 10 秒。翻译页正常内容用模拟响应验证；地区限制页面，按其公开错误块建立回归样本，验证能准确识别而不写入空资料。

调试与精简预览构建成功，Lint 为 0 错误、22 条建议警告。手机未连接，不能直接确认用户手机的 Clash 分流规则或出口状态。
