# 1.0.0 · 2026-11-02

应用版本号 7 / 1.0.0，数据库仍为版本 3。

- 移除应用设置中的特定手机品牌提示，改为通用后台与省电设置说明。
- 清理公开源码和文档中的本机用户名、安装路径、收藏统计与用户设备资料。
- 真实收藏 JSON 和网页片段改为人工编写的虚构测试样本。
- 项目原创代码采用 Apache-2.0；补齐正式运行依赖清单、许可原文和上游声明。
- 字幕编码检测库按 MPL 1.1 分发，原版源码、POM、许可和构建说明随 APK 提供；设置可查看许可、隐私说明并离线导出库源码。
- 使用独立正式签名，增加 GitHub 发布指南与密钥忽略规则。

正式版与旧 preview 签名不同，不能保证覆盖安装。当前没有应用数据导出功能，卸载旧版会丢失应用内部收藏、列表、进度和设置，源文件保留。需要旧版数据时请先保留旧安装。

原测试用户可使用单独提供的 1.0.0-preview 覆盖升级，它沿用测试签名；正式公开发布使用 1.0.0.apk。

Debug / Release / Preview 构建成功；102 项 Android 自动测试及 4 项 Python 工具测试通过；Lint 0 错误、22 条建议警告。公开源码包不含本机 SDK 配置和私钥，已独立编译；随包提供的 58 个编码检测库 Java 源文件也已重新编译。正式签名、版本、隐私残留、Git 忽略规则及 APK 内许可源码一致性已校验。真机后台行为与交互仍需设备验证。
