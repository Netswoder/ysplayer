# 目录模式与开发环境

本页仅使用虚构示例，不包含个人文件清单、收藏统计或开发者本机路径。

    Library/
      RJ99000001 Example Work/
        mp3/
          01.mp3
          01.lrc
        cover.jpg

支持同 RJ 重复包装目录、多人声优、独立封面集、双扩展名字幕、音频版本、特典与程序资源标记。双 RJ 文件夹以前面的编号为作品编号。完整扫描成功后清理失效作品；扫描失败和取消时保留原有索引。

需要 JDK 17、Android SDK Platform 36 和 Build Tools 36.0.0。Android Studio 可以为本机生成被忽略的 local.properties；命令行也可以通过 ANDROID_HOME 配置 SDK。不要把 SDK 安装目录、签名密码或本地收藏清单写入源码。
