## 0.2.0-preview · 2026-10-23

播放详情新增可横向切换的“字幕 / 封面”两页，默认显示封面。从封面区域向右滑进入当前轨道的完整字幕，向左滑返回，也可直接点击顶部页签。字幕页与封面页共用底部进度条和播放控制。

全文字幕支持：

- 上下浏览所有已解析的字幕，显示每句对应的时间。
- 高亮当前句并随播放自动滚动；字幕空白区间不错误高亮上一句。
- 手动浏览后暂停自动滚动，避免阅读中途被拉回；点击“回到当前句”恢复跟随。
- 点击某句跳转到该句开始时间；包含逐轨字幕偏移，处理音频起止边界，保留播放 / 暂停状态。
- 切轨后替换字幕并恢复默认跟随，不显示上一轨正文；无字幕时提供文件选择入口。

字幕全文直接复用播放服务已经解析的时间轴，不重新读取或另建独立计时器。长字幕采用懒加载列表显示。数据库仍为版本 1，应用包名和调试签名保持一致，版本号提升为 versionCode 2；可直接覆盖安装，保留现有应用数据。

- 字幕界面在 Robolectric API 29 / 35 上验证右滑 / 左滑、当前句高亮、偏移后的点击跳转、手动浏览与恢复跟随、切轨和无字幕状态。
