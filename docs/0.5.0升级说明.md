# 0.5.0：目录改名清理与作品库界面精简

应用版本号 6 / 0.5.0-preview，数据库仍为版本 3。包名与签名延续，可覆盖旧版安装，保留目录授权、缓存和播放数据。

## 改名后旧作品残留的原因和修复

旧扫描会把未再次发现的轨道标为不可用，但作品本身没有对应的清理步骤。给无编号目录加上 RJ 后，作品的自动归属也会改变；文件管理器使用路径式文档 ID 时，音频地址和轨道 ID 同时变化，旧作品因而可能留在书架里。

新版在授权目录完整遍历成功后，于同一数据库事务中更新音频与附件，再清理该来源已无可用轨道的作品和旧版遗留的可识别自动空壳记录。其他来源仍有可用轨道的同一作品保留；部分轨道缺失但作品仍能播放时保留作品。读取异常、失去授权或扫描取消不进入清理步骤。

对于同一来源内能唯一匹配的“原目录名 → RJ号 + 原目录名”，兼容稳定文档 ID 和路径式文档 ID：保留作品身份、手选封面、多人声优、社团、标签和收藏；轨道排序、字幕选择 / 偏移 / 编码、播放列表引用及收听进度随之迁移。旧版已经形成的可识别重复项会合并。存在多个相同候选或任意改名 / 搬动时不猜测归属，重新索引并清理已失效作品；不能保证恢复所有自定义设置。

安装后点击作品库右上角“刷新目录”触发整理。当前未监听外部文件管理器的实时改名事件。若授权的目录本身被改名且系统撤销其文档地址，请重新选择目录，或授权其父目录后扫描。

## 从作品库移除

作品详情右上角增加小垃圾桶按钮，点击后显示确认框。确认后移除作品、归属于它的轨道索引、附件索引和相关自定义列表条目，同时移出当前播放队列。播放列表本身保留。

不会删除手机上的音频、图片和字幕；手选封面的内部副本、目录授权、社团 / 声优 / 标签总库与收听历史保留。这里没有永久忽略名单：文件仍位于授权目录内时，下次扫描可以重新导入。

## 顶部布局

- 左上角以放大镜替代常驻搜索栏；点击后在“音声书架”标题位置展开搜索，并获得输入焦点。
- 返回箭头清空并收起搜索，搜索状态下仍可打开筛选。
- 最近收听、收藏、待整理移入“筛选作品”，可与声优、社团、中文标签组合；最近收听继续按最近播放时间排序。
- 删除新建空作品入口；添加音声目录、自定义播放列表和列表 / 双列切换保留。
