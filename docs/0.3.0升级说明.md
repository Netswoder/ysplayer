# 0.3.0：署名总库与双列作品库

本文记录 0.3.0 的历史行为。0.4.0 已取消失败长冷却，并加入双 RJ 取首号和中文标签，当前行为见 [0.4.0 升级说明](0.4.0升级说明.md)。

安装 `artifacts/ysplayer-0.3.0-preview.apk`，可直接覆盖同签名的旧预览版。数据库从版本 1 自动迁移到 2，原作品、封面、收藏、目录授权、列表和进度保留。最低系统仍为 Android 10。

## DLsite 信息补全

- 假定作品目录包含 RJ 编号，沿用目录导入的 RJ 作品识别。初次打开及导入新增缺失作品后，自动处理有 RJ 且社团或声优为空的作品。
- 设置页的“DLsite 社团与声优”可以关闭自动补全、手动开始、暂停、查看总库和失败原因。总库从已查询的本地作品积累，不预抓取整站名单。
- `credit_works` 缓存每部作品的来源、时间及是否存在声优栏；`credit_creators` 保存社团与声优署名，`credit_links` 保存作品与多位署名的关系。一个社团 / 声优可以关联多部作品。`credit_attempts` 保存失败冷却。
- 未缓存的 RJ 才联网；相同 RJ 在同一轮只查一次。已经成功的对应关系不自动过期，再次导入或清空展示字段时直接从本地缓存补齐。
- 作品现有非空社团 / 声优不覆盖。社团按官方 RG 编号关联，声优按官方署名分别保存，不推断别名身份。页面确实没有声优栏时保留为空并缓存“未署名”，避免反复请求。作者、画师不当作声优。
- 只有公开作品署名被获取；联网参数只有 RJ 作品地址，不上传音频、目录路径或字幕。

## 网络与恢复

应用共用一个串行客户端，请求起始至少间隔 10 秒（包括读取 robots.txt），并遵循站点声明的更长间隔。机器人规则缓存 24 小时；上次请求时间和站点退避时间跨进程保存。

连接失败通常冷却 1 小时；404 或页面解析失败冷却 24 小时。401 / 403 / 429、服务端故障或验证重定向停止当轮，遵循更长的 `Retry-After`。失败不生成成功对应，也不抹除本地资料。支持全年龄作品分区回退和同 RJ 的公开作品分区跳转，每次仍经过限速；不跟随登录、验证或其他作品跳转。网络请求有超时及响应大小限制。

补全任务与播放服务分离。暂停、系统回收进程或退出不会丢失已经完成的缓存；重新打开应用可继续处理缺失项。此版本不承诺退出后仍保持长时间联网任务，播放仍由现有前台媒体服务负责。

## 作品库与封面

数量右侧的列表 / 双列图标切换布局，选择保存在应用设置中。两种布局共用搜索、社团 / 声优筛选、最近收听、收藏、待整理和作品详情入口。

双列按参考图采用宽封面、RJ 角标、两行标题、轨道数以及社团 / 多人声优色块。标签暂不加入；尚未索引总时长，因此显示实际轨道数，不展示下载次数等无关信息。

封面改为共享 Coil 加载器，列表 / 双列 / 详情分别按尺寸加载，命中内存后直接复用。滚动时预加载邻近作品；筛选和轨道数量也做了记忆化，减少重复计算。封面无法读取时显示占位符，不阻塞滚动或播放。
